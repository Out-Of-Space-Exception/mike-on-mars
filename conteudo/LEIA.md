## Como editar

- **Rápido:** abra o arquivo aqui no GitHub e clique no lápis ✏️. Depois, **Commit changes**.
- **Planilha:** baixe o arquivo, abra no Google Sheets (Arquivo → Importar), edite e exporte como CSV com o mesmo nome. Depois, suba aqui.
- Uma pessoa por arquivo de cada vez, para um não apagar o trabalho do outro.
