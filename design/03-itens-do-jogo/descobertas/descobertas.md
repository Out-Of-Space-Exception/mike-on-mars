# Pedras das descobertas

Modelos low-poly feitos pelo time (com IA) no Blender, olhando fotos reais da NASA. Script: [descobertas.py](descobertas.py). Prévia: [descobertas-previa.png](descobertas-previa.png). Cartas: [design/05-telas/cartas-descobertas](../../05-telas/cartas-descobertas/).

| Arquivo | Descoberta | Foto da NASA usada como base |
|---|---|---|
| `veios-brancos.glb` | laje com veios brancos (Sheepbed) | [PIA16705](https://images.nasa.gov/details/PIA16705) |
| `rocknest-3.glb` | rocha Rocknest 3 | [PIA16452](https://images.nasa.gov/details/PIA16452) |
| `oxido-de-manganes.glb` | lasca com mancha escura de óxido de manganês (Windjana) | [PIA20752](https://images.nasa.gov/details/PIA20752) |
| `john-klein-a.glb` / `-b` / `-c` | as pedras A, B e C perto da John Klein | [PIA16568](https://images.nasa.gov/details/PIA16568) |
| `meteorito-lebanon.glb` | meteorito de ferro Lebanon + o pedaço do lado | [PIA18387](https://images.nasa.gov/details/PIA18387) |

- Cada modelo tem 1,1 de tamanho máximo, com a base no chão (z = 0). O Dev ajusta a escala no jogo.
- Cores chapadas por face (sem textura), como os pacotes da Kenney.
