# Dev · 10 · Envio

> **Em 1 frase:** enviar o projeto no site do Space Apps e conferir, numa aba anônima, que todos os links funcionam sem login.

- **Dupla:** Dev (Filipe e João)
- **Prazo e status:** no [TAREFAS.md](../../TAREFAS.md)
- **Precisa antes:** [dev/09-video-e-pagina](../09-video-e-pagina/PASSO.md)
- **Quem usa depois:** os jurados

## Por que importa
Um link quebrado na hora do julgamento joga fora o trabalho do time inteiro. O envio fecha **domingo, 15/11, às 23h59**. A nossa meta é 7h, para sobrar tempo de corrigir.

## Leia antes
- [CONTEXTO.md](../../CONTEXTO.md), seção 7 (regras do Space Apps)
- `video.md` em [dev/09-video-e-pagina](../09-video-e-pagina/)

## Passo a passo
1. Abrir uma **aba anônima** e testar o jogo, o repositório, o vídeo e a página do projeto.
2. Jogar 1 minuto pelo link público, no celular.
3. Enviar o projeto no site do Space Apps.
4. Abrir a página enviada numa aba anônima e conferir de novo todos os links.
5. Criar a tag `envio` (`git tag envio && git push --tags`).
6. Avisar no grupo, com o link da página enviada.

## O que entregar (nesta pasta)
| Arquivo | O que tem | Formato |
|---|---|---|
| `envio.md` | os links enviados, o horário do envio e o resultado do teste na aba anônima | `.md` |

## Pronto quando
- [ ] projeto enviado antes do prazo
- [ ] todos os links abrem numa aba anônima, sem login
- [ ] tag `envio` criada

## Não pode
- Mudar o jogo depois do envio sem testar de novo todos os links.
- Deixar algum link apontando para algo privado.
