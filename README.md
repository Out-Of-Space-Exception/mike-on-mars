# Mike on Mars 🚀

Jogo do time **Out of Space Exception** para o NASA Space Apps Challenge 2026 (desafio *Junior Astronaut Mission Trainer*).

- 🎮 **Jogar a versão do momento:** https://out-of-space-exception.github.io/mike-on-mars/ (no celular, aponte a câmera para o QR abaixo)

<img src="ferramentas/qr-code.png" width="180" alt="QR code do jogo">

## Comece aqui (3 passos)

1. **[CONTEXTO.md](CONTEXTO.md):** o jogo inteiro.
2. **[TAREFAS.md](TAREFAS.md):** ache a sua dupla, veja o horário e clique no seu passo.
3. **No `PASSO.md`:** faça o que ele diz e entregue os arquivos **na mesma pasta**.

O padrão do time está em **[AGENTS.md](AGENTS.md)**, para pessoas e para IAs. Vai usar IA? Mande ela seguir o AGENTS.md.

## Onde fica cada coisa

| Pasta | O que tem |
|---|---|
| [`design/`](design/) | um passo por pasta: Mike, cores, itens, telas, logo, ícones |
| [`conteudo/`](conteudo/) | um passo por pasta: sons, cartas, textos, slides, traduções, página, vídeo |
| [`dev/`](dev/) | um passo por pasta: do esqueleto ao envio |
| [`jogo/`](jogo/) | o jogo em si (Godot); só a dupla de Dev mexe |
| [`pesquisa/`](pesquisa/) | pesquisas com as fontes |
| [`ferramentas/`](ferramentas/) | scripts para testar e publicar |
| [`creditos.csv`](creditos.csv) | tudo o que veio de fora + onde usamos IA |

## Como subir um arquivo (sem saber git)

1. Abra a pasta do seu passo aqui no GitHub.
2. Clique em **Add file → Upload files** e arraste o arquivo.
3. Clique em **Commit changes**. Pronto.

Para editar um arquivo: abra-o, clique no lápis ✏️ e depois em **Commit changes**.
Nome de arquivo: minúsculas, sem espaço e sem acento. Ex.: `tela-inicial.png`.
